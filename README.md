# Inyectora interactiva · PhoneV

Modelo interactivo del moldeo por inyección con un molde híbrido aluminio–resina, preparado para teléfono.

Trabajo de graduación de Esli María Vivar Villatoro, Ingeniería Mecánica, Universidad del Valle de Guatemala (2026): *Elaboración de una guía de materiales para fabricar moldes de inyección de plástico mediante tecnologías aditivas en universidades*.

Sitio: https://eslivivar.github.io/inyectora-uvg/
